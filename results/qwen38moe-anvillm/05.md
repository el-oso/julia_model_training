## `Interval.jl` — Interval Arithmetic in Julia

**File structure:**
```
src/Interval.jl    — module with Interval{T<:Real} <: Real
test/runtests.jl   — full test suite
```

**Key design decisions:**

| Requirement | Solution |
|---|---|
| `Interval{T<:Real} <: Real` | Struct declaration with `T<:Real` bound |
| `lo > hi` rejection | Outer constructor validates before constructing |
| `Interval(1,2) + 1.5` → `Interval{Float64}` | `promote_rule` uses `promote_type` (not `promote_rule`) because `Base.promote_rule(Int64,Float64)` is `Union{}` in Julia 1.13 |
| No allocation on `Interval{Float64}` | Fields stored as `_data::Tuple{T,T}`; default field ctor handles exact types; `convert(T,x)` inlined for concrete T; `@inline` helpers |
| Division by zero-containing interval | `throw(DivideError())` when `lo ≤ 0 ≤ hi` |

**The `promote_rule` gotcha:** In Julia 1.13, `Base.promote_rule(Int64, Float64) == Union{}` (asymmetric). Used `promote_type` which is symmetric.

**Tests cover:** constructor validation, type propagation, allocation-free arithmetic, division-by-zero, `in`/`contains`, `show`, unary minus, singleton intervals, mixed types, and negative intervals.
