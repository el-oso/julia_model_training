## Design

| Component | Purpose |
|-----------|---------|
| `nodes::Vector{Union{Nothing, Node}}` | Slot pool — one `Node` per capacity slot; `nothing` = free |
| `key_to_idx::Dict{K,Int}` | O(1) key → slot index |
| `head`/`tail::Int` | Indices of first/last nodes (0 = empty) |
| `Node.prev`/`Node.next` | Doubly-linked list pointers (0 = no link) |

## Public API

```julia
cache = LRU{String, Int}(3)       # capacity 3
cache["a"] = 1                     # setindex! (insert, evict if full)
get(cache, "a", -1)               # O(1), no allocation on hit; touches "a"
haskey(cache, "a")                # O(1), no touch
length(cache)                     # O(1)
empty!(cache)                     # clear
keys(cache) / values(cache)       # MRU → LRU iteration
```

## Key correctness points

- **`get` on present key allocates zero**: verified by `@allocated get(c, "b", 0) == 0`
- **Reading counts as use**: `get(c, "a")` moves "a" to MRU, so a subsequent full-insert evicts the *new* LRU
- **Update is touch**: `cache["a"] = 99` updates value + moves to front
- **All O(1)**: `haskey`, `length`, `get`, `setindex!` (hit path), `empty!` (with `cache.nodes .= nothing`)
- **Base only**: no external dependencies; `Node`/`LRU` are mutable structs, linked list via Int indices, `Dict` for lookup
