**Results on 10^7 elements (~2.1M runs, mix of length-1 and length-20):**

| function | time | allocations |
|----------|------|-------------|
| `rle()`  | **8.4 ms** | 6 allocs, 31.8 MiB |
| `unrle()` | **10.1 ms** | 3 allocs, 76.3 MiB (19% GC) |

**Design choices:**

- **`isequal`** for run detection — correctly groups `NaN` and `missing` entries
- **Two-pass** (count runs → allocate → fill) avoids `push!` reallocations; the `@inbounds` on linear-index loops is fast for `AbstractVector`s including views/`OffsetArray`s
- **`eltype(v)` / `eltype(values)`** return types make it type-stable
- **`firstindex(v)` / `lastindex(v)`** handle any index origin (1-based, 0-based, offset)
- `unrle` pre-counts the total to avoid `push!` and uses `eachindex` + `@inbounds` for the fill loop
