Done. The solution is in `kmer_counter.jl`:

**Approach**: 2-bit encoding (A=00, C=01, G=10, T=11) into a `UInt64` rolling window. Each slide shifts left, ORs in the new base, and masks to 2k bits — no string slicing.

**Performance**: 10^7 bases, k=10, counted in **0.63 seconds** (well under the 1s target).

**API**:
```julia
counts, decode = count_kmers("ACGTACGT", 3)
# counts: Dict{UInt64, Int} — hash → count
# decode(code): reconstructs k-mer string from its hash
```

**Validation**: throws `ArgumentError` for invalid bases, `k > 31`, or sequences shorter than k. Accepts both upper and lowercase ACGT.
