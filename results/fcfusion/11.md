The solution works. Here's what I found:

**Result:** `fib(90) = 2880067194370816120` (computed instantly with memoization)

**Key insight:** Julia doesn't have a built-in `@memoize` macro, and generating one via macro expansion is fragile. The idiomatic approach is a **closure that captures a cache dictionary**. For recursive functions, use a `Ref` to pass the memoized function back into itself:

```julia
function memoize(f)
    let cache = Dict{Any, Any}()
        return function(x)
            if haskey(cache, x)
                return cache[x]
            end
            result = f(x)
            cache[x] = result
            return result
        end
    end
end

# Recursive case: use Ref to thread the memoized function through calls
let fib_ref = Ref{Function}()
    fib_ref[] = memoize(function(n::Int)
        if n <= 1
            return n
        end
        return fib_ref[](n - 1) + fib_ref[](n - 2)
    end)
    fib = fib_ref[]
end
```

**Limitations:**
1. Verbose — requires the `Ref` pattern for recursive functions (no clean `@memoize function f(...) end` syntax)
2. Unbounded cache — grows with unique inputs; no eviction policy
3. Only works for pure functions (same input → same output)
4. Not thread-safe — concurrent calls may compute duplicates
5. Cache keys must be hashable (primitives, strings, tuples work; arrays don't)
6. `Dict{Any, Any}` boxes values; for typed caches, use manual `Dict{Tuple{Int}, Int}`

Without memoization, `fib(90)` would take ~30 seconds (exponential time). With it, it's O(n) and completes instantly.
