```julia
using LinearAlgebra

function pairwise_dist(X)
    n = size(X, 1)
    norms = [dot(x, x) for x in eachrow(X)]  # Precompute squared norms
    G = X * X'                               # Gram matrix via GEMM
    D2 = norms .+ norms' .- 2*G              # ||x-y||² = ||x||² + ||y||² - 2(x·y)
    D2 = max.(D2, 0.0)                       # Clamp FP errors
    return sqrt.(D2)
end
```

**Key changes:**

1. **Distance formula instead of explicit differences:** Replaced `sqrt(sum((x-y)²))` with `sqrt(||x||² + ||y||² - 2(x·y))`. This avoids creating temporary arrays for each pair's difference.

2. **Precomputed squared norms:** Computed `||x_i||²` once per row instead of implicitly in each pairwise comparison.

3. **Batched dot products via GEMM:** `X * X'` computes all n² dot products at once using highly optimized BLAS matrix multiplication, replacing the inner loop entirely.

4. **Broadcasting for the final computation:** `norms .+ norms' .- 2*G` computes the full distance² matrix in one vectorized operation.

5. **Eliminated 24M temporary arrays:** The original created a temporary array for `(X[i,:] .- X[j,:]).^2` for each of the 4M pairs. The optimized version creates only 3 large arrays (norms, G, D2).
