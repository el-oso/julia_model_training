- **Richardson correction:** Uses the difference between Simpson's rule at step size h and h/2 to extrapolate to higher accuracy (O(h⁶) instead of O(h⁴))
- **Error estimation:** Based on the Richardson difference, |S(h/2) - S(h)|/15
- **Adaptive subdivision:** Recursively subdivides intervals where the error estimate exceeds the tolerance
- **No recomputation:** Function values at shared endpoints are passed down the recursion tree
- **Generic:** Works with Float32, Float64, and BigFloat via Julia's type promotion
