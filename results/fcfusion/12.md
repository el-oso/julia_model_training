The pure Julia implementation is ~5× slower than LinearAlgebra's `lu` because the latter uses optimized BLAS routines (dgetrf) with SIMD and cache-level tuning. However, our implementation:
- Works with **any field type** including `Rational{BigInt}` for exact arithmetic
- Is written in idiomatic Julia with column-major friendly loops
- Correctly handles partial pivoting and singularity detection

The implementation is in `lu_decomp.jl` with three main functions:
- `lu_pp!(A)` — in-place factorization, returns `(L, U, p)`
- `lu_pp(A)` — out-of-place version
- `lu_solve(L, U, p, b)` — solves `Ax = b` given the factorization
