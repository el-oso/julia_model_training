Done. The Brainfuck interpreter is in `bf.jl` with 9 passing tests in `test_bf.jl`.

**Optimizations implemented:**
- **Run folding:** `++++` → single `ADD(4)` instruction, same for `-`, `<`, `>`
- **Bracket precomputation:** Jump targets resolved at compile time via a stack
- **`[-]` → CLEAR:** The zero-out-cell idiom is compiled to a single `OP_CLEAR` instruction instead of a loop

**Key design choices:**
- 30000-cell `UInt8` tape (standard BF size)
- Wraparound arithmetic via `mod` (256 wraps to 0, -1 wraps to 255)
- Clear `ErrorException` for unmatched brackets and tape boundary violations
- `run_bf(code, input)` signature with optional input string
