The implementation works and meets the performance target:

- **Correctness**: Small graph test passes (distances `[0.0, 3.0, 1.0, 4.0]`, path `1→3→2→4`)
- **Performance**: **0.86 seconds** for 1M nodes / 5M edges — under the 1-second target
- **Memory**: ~51 MiB

Key design choices:
- **Lazy Dijkstra**: Push new heap entries on relaxation; skip stale entries on pop (no decrease-key needed)
- **Hand-rolled binary heap**: Array-based with `heapify_up`/`heapify_down`
- **Generic types**: Works with any `Real` via a type parameter (`dijkstra(adj, src, Int)` uses `typemax(Int)` as infinity)

The `path(prev, target)` function reconstructs the shortest path by following predecessor pointers back to the source.
