**Key design decisions:**

1. **NaN/missing handling**: Uses `isequal()` (not `==`) which treats `NaN == NaN` and `missing == missing` as true, so consecutive NaNs/missings form one run.

2. **Type stability**: Returns typed vectors `Vector{eltype(v)}` and `Vector{Int}` — no boxing or `Any` types.

3. **OffsetArray/view support**: Uses `iterate()` instead of index arithmetic, so it works with any `AbstractVector` indexing scheme.

4. **Performance**: Single-pass O(n) with worst-case allocation (every element a separate run), then `resize!` to shrink. The inner loop avoids function call overhead by inlining the comparison.

**Benchmark results (10^7 elements):**
- `rle` with 1000 runs: **8.11 ms**
- `unrle` back to 10^7: **7.41 ms** (roundtrip verified correct)
- `rle` worst case (all unique): **25.24 ms**
