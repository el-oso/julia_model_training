```julia
"""
    @memoize function f(args...) ... end
    @memoize f(args...) = ...

Define `f` so that results are cached in a `Dict` keyed by the tuple of
positional arguments. The key type is `Tuple{T1,...,Tn}` built from the argument
annotations (`Any` for unannotated arguments); the value type is the declared
return type, or `Any`. Use at top level only.
"""
macro memoize(def)
    (def isa Expr && def.head in (:function, :(=)) && length(def.args) == 2) ||
        throw(ArgumentError("@memoize expects a function definition, got $(repr(def))"))
    sig, body = def.args

    wparams = Any[]
    while sig isa Expr && sig.head === :where
        append!(wparams, sig.args[2:end])
        sig = sig.args[1]
    end
    rettype = :Any
    if sig isa Expr && sig.head === :(::)
        sig, rettype = sig.args
    end
    (sig isa Expr && sig.head === :call) ||
        throw(ArgumentError("@memoize: cannot parse the signature $(repr(sig))"))
    fname = sig.args[1]

    names = Symbol[]
    keytypes = Any[]
    wrapper_args = Any[]
    impl_args = Any[]
    for a in sig.args[2:end]
        a isa Expr && a.head === :parameters &&
            throw(ArgumentError("@memoize does not support keyword arguments"))
        hasdefault = a isa Expr && a.head === :kw
        default = hasdefault ? a.args[2] : nothing
        hasdefault && (a = a.args[1])
        if a isa Symbol
            name, T = a, :Any
        elseif a isa Expr && a.head === :(::) && length(a.args) == 2 && a.args[1] isa Symbol
            name, T = a.args
        elseif a isa Expr && a.head === :(::) && length(a.args) == 1
            name, T = gensym(:arg), a.args[1]
        else
            throw(ArgumentError("@memoize does not support the argument $(repr(a)) (varargs and destructuring are not supported)"))
        end
        push!(names, name)
        # A type that mentions a `where` parameter is not a type at definition
        # time; such keys fall back to Any.
        push!(keytypes, isempty(wparams) ? T : :Any)
        typed = :($name::$T)
        push!(impl_args, typed)
        push!(wrapper_args, hasdefault ? Expr(:kw, typed, default) : typed)
    end
    isempty(wparams) || (rettype = :Any)

    base = string(fname isa Expr ? fname.args[end] : fname)
    impl = gensym(Symbol(base, "_uncached"))
    cache = gensym(Symbol(base, "_cache"))
    K = gensym(Symbol(base, "_keytype"))
    k, v = gensym(:key), gensym(:val)

    implsig = Expr(:call, impl, impl_args...)
    wsig = Expr(:call, fname, wrapper_args...)
    if !isempty(wparams)
        implsig = Expr(:where, implsig, wparams...)
        wsig = Expr(:where, wsig, wparams...)
    end

    wbody = quote
        # With a non-concrete key type, isequal(2, 2.0) would make f(2.0) return the
        # cached f(2); keying on the argument types as well keeps them apart.
        $k = isconcretetype($K) ? ($(names...),) : (typeof(($(names...),)), ($(names...),))
        haskey($cache, $k) && return $cache[$k]::$rettype
        $v = $impl($(names...))
        $cache[$k] = $v
        return $v
    end
    return esc(quote
        const $K = Tuple{$(keytypes...)}
        const $cache = isconcretetype($K) ? Dict{$K,$rettype}() : Dict{Tuple{Type,$K},$rettype}()
        $(Expr(:function, implsig, body))
        $(Expr(:function, wsig, wbody))
    end)
end
```

### What the macro generates

For `@memoize fib(n::Int)::Int = n < 2 ? n : fib(n - 1) + fib(n - 2)` it emits three things. All internal names are `gensym`s, so they cannot clash with the argument names.

1. **A cache.** `const fib_keytype = Tuple{Int}` and `const fib_cache = Dict{Tuple{Int},Int}()`.
2. **An implementation function.** `fib_uncached(n::Int)` contains the original body unchanged.
3. **A wrapper.** `fib(n::Int)::Int` builds the key `(n,)`, returns the cached value if there is one, and otherwise calls the implementation and stores the result.

**Recursion hits the cache.** The body still calls `fib`, and `fib` is now the wrapper, so every recursive call goes through the cache. Each `fib(k)` is computed only once.

**Typed cache.** Because every annotation in `fib` is concrete, the key type `Tuple{Int}` is concrete, and the value type comes from the `::Int` return annotation. The dictionary is therefore a `Dict{Tuple{Int64},Int64}`, so lookups neither box nor allocate, and `fib` is type-stable.

**Non-concrete key types.** Here a subtle problem arises. `isequal(2, 2.0)` is `true` and the two hash equally, so a cache keyed by `(x,)` would return the cached `f(2) === 4` for `f(2.0)`. That was a real failure in my first version, caught by an `===` test. To avoid it, when the key type is not concrete the key also includes the argument types: `(typeof(args), args)`. The `isconcretetype(K)` test is on a `const`, so the compiler folds it away.

### `fib(90)` (measured)

```julia
@memoize fib(n::Int)::Int = n < 2 ? n : fib(n - 1) + fib(n - 2)

fib(90)                      # 2880067194370816120

# the gensym'd cache, looked up by name:
c = getfield(Main, only(filter(n -> occursin("fib_cache", string(n)), names(Main; all=true))))

```

### Tests

```julia
using Test

@memoize fib(n::Int)::Int = n < 2 ? n : fib(n - 1) + fib(n - 2)

const ncalls = Ref(0)
@memoize function slowadd(a::Int, b::Int = 10)
    ncalls[] += 1
    a + b
end

@memoize untyped(x) = (ncalls[] += 1; x * 2)
@memoize generic(x::T) where {T<:Real} = (ncalls[] += 1; x + one(T))
@memoize unnamed(::Int, y::Float64) = (ncalls[] += 1; y)
@memoize f0() = (ncalls[] += 1; 42)

@testset "@memoize" begin
    @test fib(90) == 2880067194370816120
    @test fib(1) == 1
    ncalls[] = 0
    @test slowadd(1, 2) == 3
    @test slowadd(1, 2) == 3
    @test ncalls[] == 1
    @test slowadd(1) == 11
    @test slowadd(1, 10) == 11
    @test ncalls[] == 2
    ncalls[] = 0
    @test untyped(2) === 4; @test untyped(2) === 4; @test untyped(2.0) === 4.0
    @test ncalls[] == 2
    ncalls[] = 0
    @test generic(1) === 2; @test generic(1) === 2; @test generic(1.0) === 2.0
    @test ncalls[] == 2
    ncalls[] = 0
    @test unnamed(1, 2.0) == 2.0; @test unnamed(1, 2.0) == 2.0; @test ncalls[] == 1
    ncalls[] = 0
    @test f0() == 42; @test f0() == 42; @test ncalls[] == 1
    @test @inferred(fib(30)) == 832040
    @test (@allocated fib(90)) == 0
    @test_throws ArgumentError macroexpand(@__MODULE__, :(@memoize f(x; y=1) = x))
    @test_throws ArgumentError macroexpand(@__MODULE__, :(@memoize f(x...) = x))
    @test_throws ArgumentError macroexpand(@__MODULE__, :(@memoize x = 1))
end
```

All 27 checks pass. They cover:
- recursion through the cache;
- default arguments (`slowadd(1)` and `slowadd(1, 10)` share one cache entry);
- untyped, `where`-parametric and unnamed (`::Int`) arguments;
- zero-argument functions;
- `@inferred` and zero allocation for `fib`;
- errors for unsupported forms.

### Limitations

- **Top level only.** It defines `const` globals, so it cannot be used inside a function or a `let` block.
- **No keyword arguments, varargs (`x...`) or destructured arguments.** These are rejected with an `ArgumentError` when the macro expands.
- **`where` parameters.** In a `where` method, the key and value types become `Any`, because `T` is not a type at definition time. Such a method still works, and the types are part of the key, but lookups box and the result is not inferred. Annotate the return type of non-parametric methods to get a typed cache.
- **Unbounded growth.** The cache never evicts anything. There is also no public way to clear it apart from finding the gensym'd global.
- **Not thread-safe.** Concurrent calls can race on the `Dict`. Add a `ReentrantLock` around the lookup and store if the function is called from several threads. The lock must be reentrant, because the function recurses.
- **Keys use `isequal` and `hash`.** If a mutable argument (for example an array) is mutated after a call, a later call with that same object returns the old result. Side effects in the body run only on a cache miss.
- **Separate caches per method.** Each `@memoize` definition gets its own cache, and redefining the method creates a new, empty cache; the old one stays in memory.
- **Plain function names only.** Callable structs (`(f::Foo)(x) = …`) and anonymous functions are not supported.
