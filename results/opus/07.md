```julia
"""
    integrate(f, a, b; rtol=1e-8, maxdepth=50) -> (value, errest)

Adaptive Simpson quadrature with Richardson extrapolation. Works in the
floating-point type of `float(a)`/`float(b)` (`Float32`, `Float64`, `BigFloat`, …).
`a > b` gives the negated integral over `[b, a]`. Emits a warning, and still
returns its best estimate, if some subinterval hits `maxdepth` before
converging. The requested `rtol` is raised to `50eps(T)` if smaller, since
tighter tolerances cannot be met in type `T`.
"""
function integrate(f, a::Real, b::Real; rtol::Real=1e-8, maxdepth::Integer=50)
    a, b = promote(float(a), float(b))
    T = typeof(a)
    a == b && return (zero(T) * f(a), zero(T))
    m = (a + b) / 2
    fa, fm, fb = f(a), f(m), f(b)
    whole = (b - a) / 6 * (fa + 4fm + fb)
    # Tolerance relative to a rough |∫f|, with a floor of roundoff level so that
    # integrals that are (close to) zero still terminate.
    scale = abs(b - a) * max(abs(fa), abs(fm), abs(fb))
    tol = max(T(rtol), 50eps(T)) * max(abs(whole), eps(T) * scale)
    val, err, hit = _simpson(f, a, m, b, fa, fm, fb, whole, tol, maxdepth)
    hit && @warn "integrate: maxdepth = $maxdepth reached on some subinterval; result may be inaccurate" errest = err
    return val, err
end

# Simpson on [a, b] with midpoint m; f values at a, m, b and the whole-interval
# estimate are passed in so each point is evaluated exactly once.
function _simpson(f, a, m, b, fa, fm, fb, whole, tol, depth)
    lm, rm = (a + m) / 2, (m + b) / 2
    flm, frm = f(lm), f(rm)
    left = (m - a) / 6 * (fa + 4flm + fm)
    right = (b - m) / 6 * (fm + 4frm + fb)
    delta = left + right - whole
    if abs(delta) <= 15tol || depth <= 0
        # Richardson: the two-panel error is ≈ delta/15
        return left + right + delta / 15, abs(delta) / 15, depth <= 0 && abs(delta) > 15tol
    end
    lv, le, lh = _simpson(f, a, lm, m, fa, flm, fm, left, tol / 2, depth - 1)
    rv, re, rh = _simpson(f, m, rm, b, fm, frm, fb, right, tol / 2, depth - 1)
    return lv + rv, le + re, lh | rh
end
```

### How it works

- **Adaptive Simpson.** On each interval `[a, b]`, the code compares Simpson's rule on the whole interval (`whole`) with the sum of Simpson's rule on its two halves (`left + right`). If `|delta| = |left + right − whole| ≤ 15·tol`, the interval is accepted. Otherwise each half is refined with half the tolerance.
- **Richardson correction.** Simpson's rule has error O(h⁴), so the two-half estimate has an error of about `delta/15`. The function returns `left + right + delta/15`, which is accurate to O(h⁶) on smooth integrands, and adds `|delta|/15` to the error estimate.
- **No repeated evaluations.** `fa`, `fm`, `fb` and `whole` are passed down the recursion, so each subdivision evaluates `f` only at the two new quarter points. Measured: `sin` on `[0, π]` used 121 evaluations, which is exactly `2·(number of panels) + 1`.
- **Generic number type.** All arithmetic is done in `T = typeof(float(a))`, and `rtol` is converted to `T`. The tolerance is raised to `50eps(T)` when it is smaller than that. Without that floor, `rtol = 1e-8` would be unreachable in `Float32`, whose `eps` is 1.2e-7, and the recursion would always run to `maxdepth`. For the same reason, the absolute tolerance has a floor at roundoff level (`eps(T)·|b−a|·max|f|`). Without it, an integral that is exactly zero, such as `sin` over `[-π, π]`, would refine everywhere down to `maxdepth` (2⁵⁰ intervals).
- **`a > b`.** The step `h = b − a` is signed, so this case needs no special handling: the result is `−∫_b^a f`, which the test checks.
- **`maxdepth`.** When an interval stops at `maxdepth` without meeting its tolerance, the function returns its best estimate and logs a single `@warn` after the recursion finishes.

All results are within `rtol = 1e-8`. The error estimate is conservative: it bounds the error of the uncorrected two-panel sum, and the Richardson-corrected value is usually much more accurate. `sqrt` needs more evaluations because its derivative is unbounded at 0, so the refinement concentrates near that endpoint. Timings: `@btime integrate(sin, 0, π)` takes 1.07 µs, and `exp(-x^2)` on [-5, 5] takes 3.0 µs. Both have 0 allocations.

### Tests

```julia
using Test, Logging
@testset "integrate" begin
    for (f, a, b, exact) in ((sin, 0, π, 2.0), (sqrt, 0, 1, 2/3),
                             (x -> exp(-x^2), -5, 5, 1.7724538509027910))  # √π·erf(5)
        v, e = integrate(f, a, b)
        @test abs(v - exact) <= 1e-8 * abs(exact)
        @test abs(v - exact) <= max(10e, 1e-14)
        v2, _ = integrate(f, b, a)
        @test v2 ≈ -v
    end
    v, e = integrate(sin, 0f0, Float32(π))
    @test v isa Float32 && e isa Float32
    @test abs(v - 2) < 1e-5
    v, e = integrate(sin, big(0), big(π); rtol=1e-20)
    @test v isa BigFloat
    @test abs(v - 2) < 1e-19
    @test integrate(sin, 1, 1) == (0.0, 0.0)
    v, _ = integrate(sin, -π, π)            # integral is zero: must terminate
    @test abs(v) < 1e-12
    v, _ = integrate(x -> 3x^2, 0, 2); @test v ≈ 8
    @test_logs (:warn, r"maxdepth") integrate(x -> sin(1/x), 1e-6, 1; maxdepth=5)
    v, e = with_logger(NullLogger()) do; integrate(x -> 1/x, 1e-300, 1; maxdepth=3); end
    @test isfinite(v)
end
```
